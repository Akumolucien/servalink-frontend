Replace it with a high-resolution photograph of a local service worker (landscape or portrait,
subject on the right). Keep the file name, or change the single import in

## Authentication image

`auth-painter.webp` (1448x1086, standalone photograph of a painter, supplied by the project owner) is the background of the
login / sign-up / recovery image panel (`components/auth/AuthVisual.tsx`, `background-size: cover`). The focal point is set
in `styles/auth.css` (`.auth-visual-img`, `background-position`). The design mockup was deliberately NOT used as an image source.
